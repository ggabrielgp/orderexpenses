Improve five dashboard interactions and surfaces requested by the user while preserving real period data, accessible controls, existing movement mutations and a shared worktree.

## Intent and constraints
- Keep the authenticated `Clasificar ahora →` action functional and keyboard-visible but visually unchanged across rest/hover/active; no button chrome.
- Compact only the edit-period modal's calendar and date fields; preserve the setup calendar and expense modal.

The later user decision removes `Ver todos` (all expenses belong in Movimientos); no unsupported relationship badges, fake dates/monthly claim or report export.

TDD off by user instruction; runner not used. Delivery strategy ask-on-risk; scope across multiple areas may exceed 400 authored lines: keep coherent tasks and report review workload before any delivery.
