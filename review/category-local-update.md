With no subsequent `loadTransactions()`, the UI can show old categories for successfully updated rows after an error. Use `Promise.allSettled()` or equivalent to apply fulfilled updates and report failed ids/count.

Since the app comment says demo mode loads fake data without backend (`public/app.js:22-23`), manual category/edit save in demo mode will fail instead of updating local state.
